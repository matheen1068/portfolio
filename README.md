# Matheen — Portfolio

Personal portfolio for Mohammed Matheen Khan, Senior DevOps Engineer.

Single static page (`index.html`): no build step, no dependencies.

## Run locally
Open `index.html` in a browser, or serve it: `python3 -m http.server 8000`

## Deploy
Hosted on Vercel as a static site (framework preset: **Other**, no build command, output directory: root).
